# VR OS v4
## 使い方(upload.bat だけでOK)
1. GitHubで空のリポジトリを作る
2. upload.bat をダブルクリック → 初回だけリポジトリURLを入れる(git/ghが無ければ自動で入れる。.gitが有っても無くても動く)
3. downloads に vros_v4.ipa と pc_sender.exe が落ちる → ipaをSideloadlyでiPhoneに入れる
4. 起動したらメニューで「VRモード」か「通常モード」を選ぶ

## VRモード(ゴーグル・横向き)
- 手を前に出すと、手が画面の仮想物より手前に見える。指先が狙い(ポインター)になる
- 選ぶ: 指先をタイルに重ねて0.8秒、またはピンチ / 手が無い時は頭の向き(1.2秒)や画面タップ
- ホームは手が届く近さ・目線より少し下に出る
- ウィンドウ内: ピンチして上下に動かすとスクロール、ピンチして離すとクリック

## 通常モード(ゴーグル無し)
- 左半分: ジョイスティック(触った所が中心) / 右半分: ドラッグで視点、タップで決定(画面中央の点)
- 左上: ホーム・キーボード、右上: VRへ、右の▲▼: スクロール
- ホームの「通常モード」タイルからも入れる

## キーボード(ウィンドウ下の⌨ か タイトルバーの⌨)
- あ/A キーで日本語/英字。ローマ字入力 → ␣ で変換(Googleの変換API。ネットが無いとひらがな/カタカナだけ)
- 変換中: ␣=次の候補 ←→=文節移動 ⏎=確定 ⌫=戻る / 候補はタップでも選べる
- タイトルバー中央をタップするとURL欄になる(URLか検索ワード)。⏎で開く
- Ctrl/Alt/Win/⇧ は次の1キーだけ(PC操作のショートカット用)
- PC窓では日本語をそのままPCへ送る(PC側のIMEは不要)
